#___________________________________________________________________
# Пример раскладки страниц:
#    3 4 5++ 6+ 7- 8*5 9+*3 10++*4 (11 12+ 13-)*7

# 3 4 - Размещает по 1 разу страницы №3 и №4 без поворота (0°)
# 5++ - Размещает 1 раз страницу №5 с поворотом 180°
# 6+  - Размещает 1 раз страницу №6 с поворотом на 90° по часовой стрелке
# 7-  - Размещает 1 раз страницу №7 с поворотом на 90° против часовой стрелки
# 8*5 - Размещает 5 раз подряд страницу №8 без поворота (0°)
# 9+*3 - Размещает 3 раза подряд страницу №9 с поворотом на 90° по часовой стрелке
# 10++*4 - Размещает 4 раза подряд страницу №10 с поворотом 180°
# (11 12+ 13-)*7 - Групповой повтор. Разворачивается в 11*7 12+*7 13-*7:
# - Размещает 7 раз страницу №11 без поворота (0°)
# - Размещает 7 раз страницу №12 с поворотом на 90° по часовой стрелке
# - Размещает 7 раз страницу №13 с поворотом на 90° против часовой стрелки
